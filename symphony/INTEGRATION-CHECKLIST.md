# Integration Verification Checklist

> One flow, one checklist. Existing-code projects add a few survey/regression items; production raises the gate strictness. No per-mode variants.
> Use at Day 0 (right after), Day 7 (1 week later), Day 30 (1 month later).

> [!NOTE]
> Check only what your **tier** introduced. Tier 1 (Karpathy + grill-me) has almost nothing to verify here; the structural items below apply once you reach Tier 2+ (SDD flow) and Tier 3 (🎸 Harness). 🎸 Harness items are optional — relevant only if a task needed an agent team.

---

## 🎯 How to Use

### Day 0
Right after integration — verify structure and operation.

### Day 7
After a week of use — verify effectiveness.

### Day 30
After a month of use — decide keep/adjust/rollback.

---

## 🔄 Rollback Guide

### Signals (every project)
- [ ] No SDD use for a whole week
- [ ] Work speed dropped 50%+
- [ ] Excessive learning burden
- [ ] The fun is gone
- [ ] Fighting the gates constantly (consider dropping a tier before rolling back)

### Existing-code extra signals (if applicable)
- [ ] Regression pass rate below 50%
- [ ] Gradual transition not working
- [ ] Big difference from archive/legacy/ behavior

---

### Staged Rollback

#### Level 1: Partial Deactivation
```bash
# Start with the most burdensome
# e.g. Harness writing every time is a burden
echo "Harness only for large features" >> .specify/memory/constitution.md
```

#### Level 2: Half Rollback
```bash
# Keep only Karpathy + grill-me (Tier 1)
rm -f .git/hooks/pre-commit .claude/hooks/pre-implement.sh   (drop the flow gates; keep Tier 1 skills)
```

#### Level 3: Full Rollback
```bash
# 1. Restore originals from archive (only if existing code was present)
#    cp -r archive/legacy/code/*   [original code location]/
#    cp -r archive/legacy/docs/*   [original docs location]/
#    cp -r archive/legacy/config/* ./
#    (greenfield has no archive, so skip this step)

# 2. Remove integration artifacts
rm -rf .claude/skills/ .claude/hooks/ .github/workflows/sdd-gate.yml   (spec-kit .specify/specs is yours)
rm -f .git/hooks/pre-commit .github/workflows/sdd-gate.yml SPEC.yml
rm CLAUDE.md DECISION-LOG.md INTEGRATION-REPORT.md INTERVIEW-RESULT.md
```

#### Git-Based Rollback (safest)
```bash
git log --oneline | grep "AI integration" | head -1
git reset --hard [commit just before integration]
```
